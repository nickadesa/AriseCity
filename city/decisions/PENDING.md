### [P-005] เทคโนโลยีเรนเดอร์ 2.5D ซูมต่อเนื่องในเว็บ
- **ความสำคัญ:** **วิกฤต (Critical)**
- **สิ่งที่ถูกบล็อก:** Architecture ของ Frontend, Data Pipeline, การ Render Scene Z0–Z4
- **ตัวเลือก:**
  - **ตัวเลือก A: WebGL 2D Engine (PixiJS v8 / Phaser 3)**
    - *ข้อดี:* ประสิทธิภาพสูงมาก เรนเดอร์สไปรต์หลักพันตัวพร้อมกันได้ 60 FPS นิ่งๆ รองรับ Smooth Zoom & Pan, Viewport Culling อัตโนมัติ, น้ำหนักเบากว่า 3D engine
    - *ข้อเสีย:* การทำ Cutaway หลังคาต้องจัดการเลเยอร์ Z-index ของ Sprite ให้แม่นยำด้วยมือ
  - **ตัวเลือก B: Three.js พร้อม Orthographic Camera (Isometric Projection)**
  - **ตัวเลือก C: HTML5 Canvas 2D + DOM Hybrid (ต่อยอดจาก AriseCity ปัจจุบัน)**
- **ผลกระทบข้ามระบบ:** ส่งผลโดยตรงต่อการเขียนโค้ด Component เรนเดอร์ และโครงสร้างข้อมูลของ Asset Catalog
- **คำแนะนำของทีม:** **เลือกตัวเลือก A (PixiJS v8)** เนื่องจากสามารถผสมผสาน Pixel Character กับ Vector Environment ได้อย่างนุ่มนวล จัดการ Smooth Continuous Zoom Z0→Z4 และมี Texture Atlas Management ที่ยอดเยี่ยม
